# Zoom Video Conference Application

## About the Project
Zoom Video Conference is a mobile application developed using Flutter to support online meetings and real-time communication. The application is designed to provide users with a convenient way to join meetings and communicate through audio and video.

## Technologies Used
- **Flutter and Dart:** Mobile application development and user interface.
- **GetX:** State management and navigation.
- **Node.js:** Backend runtime environment.
- **Express.js:** REST API development.
- **MySQL:** Database management.
- **Firebase Authentication:** User sign-in and authentication.
- **Firebase Admin SDK:** Backend verification of Firebase authentication tokens.
- **Socket.IO:** Real-time communication and WebRTC signaling.
- **WebRTC:** Audio and video communication.

## Main Features
- User authentication.
- Meeting creation and scheduling.
- Joining meetings using a room ID.
- Real-time audio and video communication.
- Meeting chat and participant communication.

## Project Purpose
The goal of this project is to develop practical skills in mobile application development, backend integration, database management, authentication, and real-time communication.
